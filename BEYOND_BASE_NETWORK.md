## 💡 Pro Tips

### Save on Gas
1. Deploy during low-traffic hours (UTC 2-6 AM)
2. Use `gasPrice: 'auto'` in hardhat config
3. Batch deployments when possible
4. Use L2 networks (cheaper than L1)

### Avoid Common Mistakes
1. **Don't** skip testnet testing
2. **Don't** deploy without audits
3. **Don't** forget to verify contracts
4. **Don't** transfer to governance too early
5. **Don't** ignore monitoring

### Best Practices
1. **Always** keep detailed deployment logs
2. **Always** have emergency procedures ready
3. **Always** test failover scenarios
4. **Always** monitor for 48+ hours post-launch
5. **Always** announce to community after stability confirmed

## 🚨 Emergency Contacts

### Protocol Pause
If you find a critical bug:
```bash
npx hardhat run --network base -e "
  const c = await ethers.getContractAt('SecurityController', 'YOUR_ADDRESS');
  await c.pauseProtocol();
"
```

### Bridge Stop
If bridge is being exploited:
```bash
npx hardhat run --network base -e "
  const b = await ethers.getContractAt('Layer8Bridge', 'YOUR_ADDRESS');
  await b.emergencyStop();
"
```

### Community Alert
- Post on Twitter/X immediately
- Update Discord announcement channel
- Email/SMS alert system (if configured)
- Contact network security teams
